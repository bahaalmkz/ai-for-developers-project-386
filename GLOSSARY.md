# Календарь звонков

Сервис бронирования времени: владелец публикует типы встреч, гость без регистрации выбирает тип и записывается на свободное время.

## Люди

**Владелец** (Owner):
Единственный хозяин календаря. Задаётся заранее, не регистрируется.
_Avoid_: админ, хост, пользователь

**Гость** (Guest):
Человек, который записывается на встречу без регистрации.
_Avoid_: клиент, посетитель, пользователь

## Бронирование

**Тип встречи** (Event Type):
Предложение владельца: название, описание и длительность.
_Avoid_: услуга, событие, категория

**Слот** (Slot):
Свободный интервал времени, на который можно записаться на выбранный тип встречи. Его длительность равна длительности типа встречи.
_Avoid_: окно, время

**Встреча** (Booking):
Подтверждённая запись гостя на слот. Занятое встречей время недоступно ни для какого типа встречи.
_Avoid_: бронь, заявка, запись (запись — это действие гостя, не сущность)

## Страницы

**Главная страница** (Home Page):
Страница `/`: рассказывает гостю о сервисе и ведёт на страницу записи.
_Avoid_: лендинг, стартовая

**Страница записи** (Booking Page):
Публичная страница `/book`, где гость выбирает тип встречи и слот.
_Avoid_: каталог, форма бронирования
